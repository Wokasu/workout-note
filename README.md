# 推し活ダイエット 📸

推しとのツーショット写真会に向けたダイエットを応援する食事管理アプリ。

## 機能

- **写真会カウントダウン**：推しの名前・推しカラー・写真会の日付を登録すると「〇〇に会えるまであと◯日」を表示。アプリ全体が推しカラーになる
- **1日の目標カロリーを自動計算**：基礎代謝（Mifflin-St Jeor 式）× 活動量から、写真会当日までに目標体重に届くカロリーを算出
  - 安全のため、基礎代謝を下回らず、減量ペースは週に体重の1%・1日700kcalまでに制限
  - 目標が無理なペースのときは警告を出し、当日の見込み体重を表示
- **食事記録**：朝・昼・夜・間食ごとに記録。カロリー目安のプリセットと「よく食べるもの」からワンタップで追加
- **体重記録**：毎日の体重とグラフ（スタートから目標までの理想ラインつき）
- **応援メッセージ**：その日の状況（未記録・目標内・オーバー・直前・当日・終了後）に合わせて応援
- **連続達成日数**：目標カロリー内に収まった日の連続記録

データはブラウザの localStorage にだけ保存されます（サーバー不要）。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm test          # ユニットテスト（vitest）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run build:single  # 1ファイルにまとめた dist/oshi-diet.html を作る
```

React 18 + TypeScript + Vite。`dist/` は相対パスでビルドされるので、GitHub Pages などの静的ホスティングにそのまま置けます。

> カロリーや体重の数値は目安です。持病のある方や体調に不安がある方は医師に相談してください。

# AKB48 劇場公演カレンダー 📅

推しメンが出演する AKB48 劇場公演を、iPhone のカレンダーに自動で入れる仕組みです（`akb48-calendar/`）。

| カレンダー | 対象メンバー | 色 |
| --- | --- | --- |
| AKB48 伊藤百花 | 伊藤百花 | 紫 |
| AKB48 奥本カイリ・渡邉葵心 | 奥本カイリ、渡邉葵心 | 水色 |

GitHub Actions（`.github/workflows/akb48-calendar.yml`）が3時間ごとに AKB48 公式サイトの
「AKB48劇場 公演スケジュール更新のお知らせ」（1か月分の出演メンバー）と「〇月〇日 「…」公演のご案内」（1公演ぶんの最新メンバー）を読み、
推しメンの名前がある公演だけを `.ics` にして `akb48-calendar-feed` ブランチに置きます。
開演時刻がお知らせに書かれていないときは、トップページの劇場スケジュール一覧から補います。
iPhone はこの `.ics` を「照会するカレンダー」として購読するので、一度登録すれば後は自動で更新されます。

## iPhone への登録

1. 「設定」→「カレンダー」→「アカウント」→「アカウントを追加」→「その他」→「照会するカレンダーを追加」
2. サーバに次の URL を入れて「次へ」→「保存」（2つとも登録）
   - 伊藤百花: `https://raw.githubusercontent.com/Wokasu/workout-note/akb48-calendar-feed/momoka.ics`
   - 奥本カイリ・渡邉葵心: `https://raw.githubusercontent.com/Wokasu/workout-note/akb48-calendar-feed/kairi-kiko.ics`
3. カレンダーアプリ →「カレンダー」→ 各カレンダーの ⓘ で色を **紫** / **水色** に設定
   （iPhone は購読カレンダーの色指定を無視することが多いので、ここで一度だけ設定します）

更新頻度は「設定」→「カレンダー」→「アカウント」→「照会するカレンダー」から変えられます。

## しくみ・注意

- 推しメンが複数出る公演（例：伊藤百花と奥本カイリ）は、両方のカレンダーに入ります
- 予定のタイトルは `「公演名」公演（出演した推しメン）`。メモに出典 URL が入ります。終了時刻は開演の2時間後で仮置き
- 1日2公演の日は2つの予定になります。時刻ごとに出演メンバーが違う日（例：【14:00公演 出演メンバー】）も分けて判定します
- 同じ公演のメンバーが「スケジュール更新」と「ご案内」の両方にあれば、新しい「ご案内」を使います。
  メンバー変更で推しが外れたら次の更新で予定も消えます。過去の公演は残ります
- 「【本日の劇場公演】出演メンバー変更のお知らせ」のような文章だけのお知らせは読めません（当日の急な変更は反映されないことがあります）
- サイトに取りに行けなかったときは前回の予定をそのまま残し、Actions を失敗にして知らせます
- 2026年11月1日より前の公演は入れません（`config.json` の `startDate`）
- メンバーや色・読みに行くページは `akb48-calendar/config.json` で変えられます

```bash
node --test akb48-calendar/test.mjs                       # テスト
node akb48-calendar/update.mjs --out feed --dump dump    # 手元で .ics を作る（dump/ に読み取ったテキスト）
```

公式サイトのページ構成が変わって予定が入らなくなったときは、Actions の実行結果にある `fetched-text`（サイトから読み取ったテキスト）を見て
`akb48-calendar/lib.mjs` の読み取りルールを直してください。

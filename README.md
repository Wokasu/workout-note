# 推し活ダイエット 📸

推しとのツーショット写真会に向けたダイエットを応援する食事管理アプリ。

## 機能

- **写真会カウントダウン**：推しの名前・推しカラー・写真会の日付を登録すると「〇〇に会えるまであと◯日」を表示。アプリ全体が推しカラーになる
- **1日の目標カロリーを自動計算**：基礎代謝（Mifflin-St Jeor 式）× 活動量から、写真会当日までに目標体重に届くカロリーを算出
  - 安全のため、基礎代謝を下回らず、減量ペースは週に体重の1%・1日700kcalまでに制限
  - 目標が無理なペースのときは警告を出し、当日の見込み体重を表示
- **食事記録**：朝・昼・夜・間食ごとに記録。カロリー目安のプリセットと「よく食べるもの」からワンタップで追加
- **体重記録**：毎日の体重とグラフ（スタートから目標までの理想ラインつき）
- **応援メッセージ**：その日の状況（未記録・目標内・オーバー・直前・当日・終了後）に合わせて応援
- **連続達成日数**：目標カロリー内に収まった日の連続記録

データはブラウザの localStorage にだけ保存されます（サーバー不要）。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm test          # ユニットテスト（vitest）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run build:single  # 1ファイルにまとめた dist/oshi-diet.html を作る
```

React 18 + TypeScript + Vite。`dist/` は相対パスでビルドされるので、GitHub Pages などの静的ホスティングにそのまま置けます。

> カロリーや体重の数値は目安です。持病のある方や体調に不安がある方は医師に相談してください。

# AKB48 劇場公演カレンダー 📅

推しメンが出演する AKB48 劇場公演を、iPhone のカレンダーに自動で入れる仕組みです（`akb48-calendar/`）。

| カレンダー | 対象メンバー | 色 |
| --- | --- | --- |
| AKB48 伊藤百花 | 伊藤百花 | 紫 |
| AKB48 奥本カイリ・渡邉葵心 | 奥本カイリ、渡邉葵心 | 水色 |

GitHub Actions（`.github/workflows/akb48-calendar.yml`）が3時間ごとに AKB48 公式サイトの
「AKB48劇場 公演スケジュール更新のお知らせ」（1か月分の出演メンバー）と「〇月〇日 「…」公演のご案内」（1公演ぶんの最新メンバー）を読み、
推しメンの名前がある公演だけを `.ics` にして `akb48-calendar-feed` ブランチに置きます。
開演時刻がお知らせに書かれていないときは、トップページの劇場スケジュール一覧から補います。
iPhone はこの `.ics` を「照会するカレンダー」として購読するので、一度登録すれば後は自動で更新されます。

### 握手会・ライブ・イベントなどの「現場」

公式サイトの「スケジュール」ページと同じデータ（`/public/api/schedule/calendar/`）を今月から3か月先まで読み、
推しメンが出演メンバーに入っている **直接会いに行ける現場** も同じカレンダー（同じ色）に入れます。

| 入れる | 入れない |
| --- | --- |
| 握手会・写真会・お話し会（オンラインお話し会も）、ライブ・コンサート、イベント（募金活動・フェスなど） | テレビ・ラジオ・雑誌・新聞・ネット配信 |
| テレビ・ラジオの公開収録・公開録音・公開生放送 | 握手会以外の「オンライン」「配信」の予定 |

予定には会場と詳細ページのURL（本文の「＜詳細＞」や「【公式サイト】」のリンク）が入ります。
出演メンバーが書かれていないグループ全体の予定（例：「出演者 AKB48」）は「出演メンバー未発表」として両方のカレンダーに入ります。

### 公式スタッフブログ（イベント候補の通知）

公式スタッフブログ（Ameba「akihabara48」）の新着記事（RSS）も読みます。

- 劇場の「公演のご案内」「受付開始のお知らせ」は、公式サイトのお知らせと同じように劇場公演として取り込みます（公式サイトのニュースが止まっていても拾えます）
- それ以外で推しメンの名前が出てくる新しい記事は「📰 推しメンのイベント候補」として ntfy に届きます（タップで記事が開きます）。
  文章から日時や会場を正しく読み取れるとは限らないので、**カレンダーには自動で入れません**。入れたいものは Claude に伝えてください
- テレビ・ラジオ・雑誌・MV・Instagram開設などの記事は候補にしません（`config.json` の `blogIgnorePattern`）
- 読むブログは `config.json` の `blogFeeds`（書かなければ公式スタッフブログ）。知人用の設定でも同じように動きます
出演者が別の情報で分かっているときは、`config.json` の `knownMembers` に書くとその推しのカレンダーに入ります（公式にメンバーが載ったらそちらを使います）。

## iPhone への登録

1. 「設定」→「カレンダー」→「アカウント」→「アカウントを追加」→「その他」→「照会するカレンダーを追加」
2. サーバに次の URL を入れて「次へ」→「保存」（2つとも登録）
   - 伊藤百花: `https://raw.githubusercontent.com/Wokasu/workout-note/akb48-calendar-feed/momoka.ics`
   - 奥本カイリ・渡邉葵心: `https://raw.githubusercontent.com/Wokasu/workout-note/akb48-calendar-feed/kairi-kiko.ics`
3. カレンダーアプリ →「カレンダー」→ 各カレンダーの ⓘ で色を **紫** / **水色** に設定
   （iPhone は購読カレンダーの色指定を無視することが多いので、ここで一度だけ設定します）

更新頻度は「設定」→「カレンダー」→「アカウント」→「照会するカレンダー」から変えられます。

## しくみ・注意

- 推しメンが複数出る公演で伊藤百花が含まれるもの（例：伊藤百花と奥本カイリ）は、伊藤百花のカレンダー（紫）にだけ入ります。タイトルには出演する推しが全員書かれます
- 予定のタイトルは `「公演名」公演（出演した推しメン）`（生誕祭・女性限定公演は `「公演名」公演【女性限定公演】（…）`）。メモには推しメン以外も含めた出演メンバー全員と出典 URL が入ります。終了時刻は開演の2時間後で仮置き
- 1日2公演の日は2つの予定になります。時刻ごとに出演メンバーが違う日（例：【14:00公演 出演メンバー】）も分けて判定します
- 同じ公演のメンバーが「スケジュール更新」と「ご案内」の両方にあれば、新しい「ご案内」を使います。
  メンバー変更で推しが外れたら次の更新で予定も消えます。過去の公演は残ります
- 「【本日の劇場公演】出演メンバー変更のお知らせ」のような文章だけのお知らせは読めません（当日の急な変更は反映されないことがあります）
- サイトに取りに行けなかったときは前回の予定をそのまま残し、Actions を失敗にして知らせます
- 2026年10月18日より前の公演は入れません（`config.json` の `startDate`）
- メンバーや色・読みに行くページは `akb48-calendar/config.json` で変えられます

```bash
node --test akb48-calendar/test.mjs                       # テスト
node akb48-calendar/update.mjs --out feed --dump dump    # 手元で .ics を作る（dump/ に読み取ったテキスト）
```

公式サイトのページ構成が変わって予定が入らなくなったときは、Actions の実行結果にある `fetched-text`（サイトから読み取ったテキスト）を見て
`akb48-calendar/lib.mjs` の読み取りルールを直してください。

## 申込開始・申込締切の通知

通知の対象は、`config.json` の推しメン（伊藤百花・奥本カイリ・渡邉葵心）が出る劇場公演だけです。
申込締切は `targetFrame` の応募枠（柱の会会員枠＝(2)。締切は「(1)〜(3)枠」のもの）だけを扱います。

- **申込開始**：推しが出る劇場公演に申込ページのリンクが載ったら（＝申込が始まったら）、「申込開始 10/21 14:17」という Issue が立ち、GitHub の通知が届きます。
  公演・申込リンク・応募枠ごとの締切が書かれています
  - 同じ内容をプッシュ通知アプリ **ntfy** にも送ります。GitHub の Secrets に `NTFY_TOPIC`（トピック名）を登録し、
    通知を受けたい人がそれぞれ ntfy アプリでそのトピックを購読します（GitHub アカウント不要。トピック名を知っている人は誰でも受信できるので、推測されにくい名前にして共有する相手だけに伝える）。
    Actions の Run workflow で `ntfy_test` にチェックを入れて実行すると、テスト通知が届きます
- **申込締切の1日前（ntfy）**：締切の24時間前ちょうどに、1公演・1応募枠ごとに ntfy でプッシュ通知します
  （「⏰ 明日が申込締切です」＋公演と締切。タップするとその公演の申込ページ）。3時間ごとのチェックで、
  4時間以内に24時間前を迎えるものを ntfy の予約送信で送り、送った記録は feed の `ntfy-sent.json` に残します
- **申込締切の1日前（カレンダー）**：3つ目のカレンダー「AKB48 申込締切」（`deadlines.ics`）に、応募枠（(1)〜(3)枠、(4)〜(6)枠）ごとの締切が入り、締切の24時間前に通知が鳴ります。
  同じ締切の公演は1つの予定にまとまります。ロビー観覧チケットの締切は入れません

iPhone で登録するときは、「照会するカレンダーを追加」の画面で **「通知を削除」をオフ** にしてください（オンだと通知が鳴りません）。

```
https://raw.githubusercontent.com/Wokasu/workout-note/akb48-calendar-feed/deadlines.ics
```

## SNS出演告知文

来月以降の劇場公演のスケジュールが公式に出ると、推しメンごとに次の形の告知文を自動で作ります。

```
11月出演公演🧤🤍

「ここからだ」
3日㈫ 13:00／17:30
5日㈭ 18:30

○柱の会限定イベント
15日㈰ 14:00
```

- できた告知文は `akb48-calendar-feed` ブランチの `sns/YYYY-MM/<名前>.txt`（3人ぶんまとめたものは `sns/YYYY-MM.txt`）
- 新しい月の告知文ができると「出演告知文 2026年11月」という Issue が立ち、GitHub の通知が届きます。出演メンバーが変わったときはその Issue にコメントで新しい告知文が届きます
- 見出しの絵文字は `config.json` の各メンバーの `snsEmoji` で変えられます

### X（旧Twitter）への自動投稿

新しい月の告知文ができたら、自分の X アカウントに推しメンごとに投稿します（先頭に `【伊藤百花】` のような見出しが付きます。
`config.json` の `xHeading` で変更可）。280文字（日本語は1文字を2と数える）を超えるときは演目ごとにスレッドに分けます。
投稿は月ごと・メンバーごとに1回だけで、記録は `akb48-calendar-feed` の `sns/posted.json` に残ります。メンバー変更があっても投稿し直しはしません（Issue で知らせるだけ）。

準備:
1. [X Developer Console](https://console.x.com) でアプリを作り、権限を **Read and write** にする
2. API Key / API Key Secret / Access Token / Access Token Secret を発行する（権限を変えた後に Access Token を作り直す）
3. GitHub のリポジトリ → Settings → Secrets and variables → Actions に `X_API_KEY` `X_API_SECRET` `X_ACCESS_TOKEN` `X_ACCESS_TOKEN_SECRET` として登録する

すでにできている月を投稿したいときは、Actions の「AKB48 劇場公演カレンダー更新」→ Run workflow で `x_post_month` に `2026-11` のように入れて実行します。

## 申込ランチャー（Windows）

推しが出る公演の申込ページ（AKB48チケットセンター）を、Chromeのプロファイル＝申込アカウントごとに **1アカウントずつ** 開きます。
ページを開くだけで、ログイン・入力・申込ボタンは自分で操作します（ZAIKO利用規約 第8条第7号の「自動化された手段によるアクセス」はしません）。

### 準備（最初の1回）
1. Chromeでプロファイルを作り、名前を `AKB 01`、`AKB 02`、… `AKB 24` のように **「AKB」＋2桁の番号** で始める（後ろにメモを付けてもOK：`AKB 01 柱の会`）
2. 各プロファイルでチケットセンターにログインしておく
3. `akb48-calendar/launcher/` の `launcher.bat` と `launcher.ps1` を同じフォルダに保存する

### 使い方
1. `launcher.bat` をダブルクリックして、`1`（申込ページを開く）か `2`（全アカウントのログイン確認）を選ぶ
   - `2` はチケットセンターを `AKB 01` から順に開くので、ログインが切れていたらその場でログインし直す。申込開始の前にやっておく
2. `1` を選ぶと推しが出る公演の一覧が出るので、開く公演の番号を入れる（例: `1-5`、`1,3,4`）
3. `AKB 01` のウィンドウに選んだ公演が開く → 申し込む → Enter で `AKB 02` へ … をくり返す（`q` で終了）

申込ページのリンクは、公式サイトに申込開始とともに載るもの（トップページの「★お申し込みはコチラ」や、お知らせの「AKB48チケットセンターにて受け付けいたします」のリンク）をそのまま使います。
URLの形は公演ごとにばらばらなので、自分で組み立てることはしません。まだ申込が始まっていない公演はリンクがなく、一覧に「まだ申込が始まっていません」と出て開きません。
`launcherExclude` の公演（柱の会限定イベント）、申込受付が終わった公演（一般枠も含めてすべての応募枠の締切が過ぎ、ロビー観覧しか残っていないもの。締切が公式サイトに見当たらない公演は、一般枠の決まり＝公演日の5日前の16時（config.json の `generalDeadline`）で判断）、女性限定公演は一覧に出しません。
生誕祭・女性限定公演は、公式サイトの但し書きを公演名の後ろに付けて表示します（カレンダーの予定名も同じ）（例: `「RESET」公演【女性限定公演】`、`「ここからだ」公演【坂川陽香 生誕祭】`）。
自分で決めたURLを開きたいときは、`launcher.bat` と同じフォルダに `urls.txt`（1行に1つURL）を置くとそちらを使います。

# 百花クエストⅠ THE LAST WOTA 〜消えないペンライトの灯〜 🎮

ファミコン時代の RPG 風ドット絵ゲーム（`momoka-quest/index.html`）。ヲタクの「ヲタ太」が、推しメン・伊藤百花をさらった同担拒否魔王キョヒールと推し被りのヲタクたちを倒し、百花を救って結婚するまでの物語。

- 「はじめから」で主人公の名前を決められます（文字表から選ぶか、キーボードで入力。漢字もOK・6文字まで。決めないと「ヲタ太」）
- 1ファイルの HTML（ビルド不要）。ブラウザで `momoka-quest/index.html` を開くだけで遊べます
- 操作：矢印キーで移動、Z / Enter で決定・はなす、X / Esc でキャンセル・メニュー。スマホでは画面下の十字キーと A/B ボタン
- 流れ：アキハバラの劇場で公演 → 握手会場で TOのゴウ を倒して通行証 → 推し被りの塔でキョヒールを倒す → エンディング
- 冒険は自動でセーブされ、タイトルの「つづきから」で再開できます。セーブ先はブラウザ（localStorage）と、claude.ai で公開したページではログイン中の本人用の保存領域。タイトル画面の下に今のセーブ先が出ます
- どこでも使える「ふっかつのじゅもん」：メニューの「きろく」でコピーし、タイトルの「じゅもんで さいかい」に貼ると続きから遊べます
- 家（母）とネットカフェでは回復できます
- クリアすると、タイトルに「強くてニューゲーム」が出ます。レベル・装備・お金・持ち物・エピソードで覚えた特技を引き継いで最初から遊べます（周回ごとに敵が1.5倍ずつ強くなります）
- 効果音・BGM は WebAudio で鳴らすチップチューン。パルス波（デューティ比 12.5/25/50%）・デチューン・ビブラート・ドラム・エコー入り。フィールド曲「推し活の旅路」はイース風の疾走感を目指したオリジナル曲（右下の「サウンド」ボタンで ON/OFF）

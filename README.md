# 推し活ダイエット 📸

推しとのツーショット写真会に向けたダイエットを応援する食事管理アプリ。

## 機能

- **写真会カウントダウン**：推しの名前・推しカラー・写真会の日付を登録すると「〇〇に会えるまであと◯日」を表示。アプリ全体が推しカラーになる
- **1日の目標カロリーを自動計算**：基礎代謝（Mifflin-St Jeor 式）× 活動量から、写真会当日までに目標体重に届くカロリーを算出
  - 安全のため、基礎代謝を下回らず、減量ペースは週に体重の1%・1日700kcalまでに制限
  - 目標が無理なペースのときは警告を出し、当日の見込み体重を表示
- **食事記録**：朝・昼・夜・間食ごとに記録。カロリー目安のプリセットと「よく食べるもの」からワンタップで追加
- **体重記録**：毎日の体重とグラフ（スタートから目標までの理想ラインつき）
- **応援メッセージ**：その日の状況（未記録・目標内・オーバー・直前・当日・終了後）に合わせて応援
- **連続達成日数**：目標カロリー内に収まった日の連続記録

データはブラウザの localStorage にだけ保存されます（サーバー不要）。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm test          # ユニットテスト（vitest）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run build:single  # 1ファイルにまとめた dist/oshi-diet.html を作る
```

React 18 + TypeScript + Vite。`dist/` は相対パスでビルドされるので、GitHub Pages などの静的ホスティングにそのまま置けます。

> カロリーや体重の数値は目安です。持病のある方や体調に不安がある方は医師に相談してください。

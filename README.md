# 筋トレノート

手書きの筋トレノートを写真やテキストから取り込み、記録・グラフ・重量計算ができるアプリ。

- 公開先（claude.ai アーティファクト）: https://claude.ai/artifact/EMhv224TFshWWqTUjbg3bk
- ソース: `workout-note.html`（1ファイル完結。ビルド不要）

## 構成

`workout-note.html` の中身は次の3つ。

1. `<style>`：見た目（色はすべて `:root` の CSS 変数。ダークモード対応）
2. 1つ目の `<script>`：計算ロジック（`WN`）。記録の読み取り、1RM 推定、ボリューム集計、バックアップなど
3. 2つ目の `<script>`：画面（タブ・各画面の描画・保存）

記録データはアーティファクトのデータベースに保存されるため、HTML を更新しても記録は消えません。

## 更新のしかた

`workout-note.html` を編集し、同じ URL のアーティファクトに上書き公開する。公開した内容はこのリポジトリにもコミットしておく。
